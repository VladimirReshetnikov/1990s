# 1990s-style browser games

Each game lives in its own folder and is self-contained (its own engine copy, no build step).
Open the game's `index.html` in a browser, or serve this folder with
`python -m http.server 8000` and browse to `http://localhost:8000/<folder>/`.

| Folder | Game |
| --- | --- |
| [`hollowmere/`](hollowmere/) | **Hollowmere** — Doom-style first-person adventure in a haunted astronomer's manor (plus the *Blackwater Light* variation). See its README for controls and for creating variations. |
